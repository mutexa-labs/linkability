# Changelog

All notable changes to this package are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the package uses semantic versioning.

## [0.1.0] - 2026-10-18

### Added

- `SPEC.md`, spec version 1: scale, levels, every factor with a stable id, the observed-input rules and what
  the score does not measure.
- `linkability` scorer with factor ids and `specVersion`.
- `observedInput` and `timingClass` for building the input from public records.
- `verifyAccounts` and the `linkability verify` CLI for Hyperliquid accounts.
- 20 golden vectors in `vectors/score.json`.
